# Bunny Code (Automation)

Bunny Code builds intelligent workflow automations that eliminate manual work and reduce operational friction.

Core capabilities:
- Workflow automation (replace repetitive tasks)
- AI-powered logic (classify, route, generate, decide in real time)
- Tool & API integrations (CRMs, databases, messaging, SaaS)
- Lead & sales automation (capture → qualify → follow-up → reporting)
- Monitoring & reliability (logging, alerts, health checks)
- Internal operations automation (reporting, approvals, syncing)
- Support & communication automation (routing, escalation, responses)

Offers include pre-built automation packages and custom automation packages.
